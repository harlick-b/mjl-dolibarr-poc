# MJL Financement v2 — Material Gap Matrix

## Baseline and method

- Baseline branch: `main`
- Baseline commit: `e8bfb15b5c1f359f45824ff14f7d72e869386587`
- Approved design: [MJL Financement v2](../design-system/approved/v2/DESIGN.md)
- Approved snapshot tree: `98d0053a934b83b4a21a6c67207e86b3c89fe7d0`
- Working-tree overlay at audit start: none

The matrix compares the committed implementation with the immutable approved
v2 package. `None` in the overlay column means that no
`UNCOMMITTED_WORKING_TREE_EVIDENCE` existed at the recorded baseline.

Blocking-scope precedence is: `BLOCKS_IMPLEMENTATION` only when no safe phase
can start; `BLOCKS_SPECIFIC_PHASE` when a named later phase is blocked;
`BLOCKS_RELEASE` when implementation is safe but release is not; otherwise
`NON_BLOCKING`.

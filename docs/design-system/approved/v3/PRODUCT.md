# MJL Financement Product Definition

Status: `APPROVED`

MJL Financement is the invitation-only, French-first Dolibarr workspace for
monitoring externally funded Ministry of Justice and Legislation projects.
Product meaning, roles, permissions, scope, workflows, documents, and exports
remain governed by `docs/mjl-authoritative-decisions.md`.

The design system supports the existing workspace, authentication flows,
administrative dashboards, operational forms and tables, guarded documents,
audit histories, alerts, and CSV/XLSX report surfaces. It changes visual
presentation only. It does not change database meaning, workflow transitions,
role authorization, entity isolation, export formats, or email contracts.

The experience is institutional, sober, calm, and mission-oriented. It hides
unnecessary ERP complexity while keeping server-side guards authoritative.
Desktop is the primary working environment, with usable responsive and
coarse-pointer behavior.

No public registration, PDF or Word reporting, new icon framework, switch
component, or Dolibarr core modification is introduced by v3.

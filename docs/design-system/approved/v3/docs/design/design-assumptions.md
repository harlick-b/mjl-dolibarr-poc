# v3 Design Assumptions

- No approved local Inter asset or font build pipeline exists in the repository.
- The user-approved Google Fonts CSS2 endpoint is therefore the browser source.
- Production reverse-proxy CSP, egress, and privacy policy is not confirmed.
- Browser fallback remains required when Google Fonts is blocked or unavailable.
- Emails and server-generated CSV/XLSX output remain independent of browser fonts.
- Desktop is primary, but 390px through wide desktop and coarse-pointer use remain supported.
- Final brand assets, icon policy, client wording, and official report canevas remain unconfirmed.
- A switch component is not authorized; only reusable switch dimensions are recorded.
- Manual accessibility evidence remains unsigned and no WCAG claim is made.

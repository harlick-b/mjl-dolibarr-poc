# MJL Clarity System Tokens

The canonical token authority is the approved v3 package:

- [`approved/v3/design-tokens/tokens.json`](approved/v3/design-tokens/tokens.json)
- [`approved/v3/design-tokens/semantic-tokens.json`](approved/v3/design-tokens/semantic-tokens.json)
- [`approved/v3/design-tokens/README.md`](approved/v3/design-tokens/README.md)

Runtime CSS maps those values inside MJL-scoped selectors. This pointer does
not define a second token set. Product decisions remain governed by
`docs/mjl-authoritative-decisions.md`.

Status and severity must always retain visible text or another non-color cue.
Any palette or typography replacement requires alias, contrast, focus,
responsive, state, and fallback revalidation.

# Retired MJL POC Sample Data Pack

This package describes obsolete POC data and is retained temporarily only so
RST-000A can inventory and remove every legacy seed source safely. RST-014A
later provides isolated Phase 1 test-record factories without replacing it.

Do not load, copy, migrate, transform, or use these files to infer, validate,
or justify target business rules. Normal local startup must remain empty after
the approved clean reset except for one native technical administrator.

Target tests use minimal disposable records created inside isolated tenants and
destroyed with those tenants. They do not read this package. A new persistent
sample/demo dataset may be specified only after all implementation phases are
complete; it will be derived from final authoritative rules, not from this
legacy package.

Authoritative decisions are in
`../docs/mjl-authoritative-decisions.md`; deletion scope and approval are owned
by `../docs/mjl-reset-manifest-v2.md`.
